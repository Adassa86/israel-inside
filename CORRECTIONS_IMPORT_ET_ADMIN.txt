VERSION CORRIGÉE — ISRAËL INSIDE

Ce projet conserve exactement la logique de connexion existante :
- DATABASE_URL si elle est définie ;
- sinon sqlite:///jobs.db.

Corrections réalisées :
1. Import OpenAI : le client Python ignore les proxys Windows/VPN défectueux (trust_env=False).
2. Import massif : taille de formulaire augmentée à 12 Mo pour éviter l'erreur 413.
3. Chaque offre est enregistrée immédiatement après son analyse.
4. Administration privée des publicités : ajouter, modifier, masquer et supprimer.
5. Les publicités publiées s'affichent automatiquement dans la colonne de droite.

- Définir OPENAI_API_KEY et DATABASE_URL dans la même fenêtre si nécessaire.
- Tester OpenAI : py test_openai_connection.py
